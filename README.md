# React Learning Journey

A collection of projects built while learning React.js, starting with the fundamentals and gradually progressing toward interactive, API-driven applications. Each project focuses on understanding core concepts through hands-on implementation.

## What I'm Learning

- React components, JSX, and props
- State management using `useState`
- Event handling and dynamic rendering
- React Hooks: `useEffect`, `useId`, and custom hooks
- API integration and asynchronous data fetching
- Controlled inputs and form handling
- Tailwind CSS and responsive UI development
- Component reusability and clean code structure

## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd project-folder
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Follow the terminal instructions to open the application locally.
